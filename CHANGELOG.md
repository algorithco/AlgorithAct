# Changelog

Version 0.1.0 is the initial alpha source snapshot. This file does not announce a published installer.

## Unreleased

- Crisp desktop icon variants generated from the original artwork.
- Custom window controls with native state synchronization and save/discard/cancel handling on close.

- English/Uzbek project documentation, contribution/security policies and GitHub issue/PR templates.
- MIT licensing, third-party notices and generated dependency license texts in builds.
- PR CI, dependency update configuration and local documentation link checks.
- Explicit checksum-verified download of the pinned Windows FFmpeg runtime.
- Patched Electron and Vitest toolchain versions before public source publication.

## 0.1.0 alpha — 2026-10-27

- Local React/PixiJS/Electron 2D workspace, two original rigs and five reusable motions.
- Keyframes, easing, pose editing, transforms, text/images, camera evaluation and undo/redo.
- Audio waveforms, trim/gain/mute/fades, preview synchronization and offline mixing.
- `.anim` project files, integrity checks, recovery and desktop backups.
- PNG and MP4/WebM export with progress/cancel and FFprobe validation.
- Windows x64 packaging, bundled media tools, branding and an NSIS build script.
- Unit/property, browser, native and packaged tests, golden frames and benchmark records.

AI Build remains a placeholder. Cross-platform packages, project fonts, scene-settings UX and remaining performance/recovery gates are on the [roadmap](docs/ROADMAP.md).
