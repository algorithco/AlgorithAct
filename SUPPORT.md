# Getting help

Start with [getting started](docs/GETTING_STARTED.md), the [user guide](docs/USER_GUIDE.md) and [troubleshooting](docs/TROUBLESHOOTING.md).

Open a [GitHub issue](https://github.com/algorithco/AlgorithAct/issues/new/choose) for bugs or proposals. Include operating system, app/commit version, exact steps, expected and actual results. For development problems, include the command and relevant error. English and Uzbek are welcome.

Use small synthetic samples. `.anim` files embed media; inspect them before sharing. Remove secrets, personal paths and private audio from attachments. Report vulnerabilities through [SECURITY.md](SECURITY.md). Support for this alpha is best-effort, without response-time commitments.
