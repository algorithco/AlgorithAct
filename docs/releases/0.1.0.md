# AlgorithAct 0.1.0 — First desktop alpha

The first downloadable release of AlgorithAct, an offline desktop studio for original 2D character animation.

## Downloads

| System | Processor | Download |
| --- | --- | --- |
| Windows | Intel/AMD 64-bit | `AlgorithAct-Setup-0.1.0-x64.exe` |
| macOS 13+ | Apple Silicon | `AlgorithAct-0.1.0-macOS-arm64.dmg` or `.zip` |
| macOS 13+ | Intel | `AlgorithAct-0.1.0-macOS-x64.dmg` or `.zip` |
| Linux | Intel/AMD 64-bit | `AlgorithAct-0.1.0-Linux-x64.AppImage` or `.tar.gz` |
| Linux | ARM64 | `AlgorithAct-0.1.0-Linux-arm64.AppImage` or `.tar.gz` |

Windows: run the installer. macOS: open the disk image and drag AlgorithAct into Applications. Linux: make the AppImage executable and launch it, or extract the tar archive and run `AlgorithAct`. AppImages need FUSE support; the tar archive is available for systems without FUSE. Linux builds use Ubuntu 24.04 (glibc 2.39 or newer).

Every package includes Electron, FFmpeg and FFprobe. Node.js, a separate FFmpeg installation, an account and an internet connection are unnecessary for editing and export.

## Available now

- Original and Novcha characters, reusable motions, pose handles, keyframes and easing.
- Text, images, layers, timeline controls, camera animation and undo/redo.
- Audio waveforms, trimming, gain, fades and offline stereo mixing.
- Portable `.anim` projects with embedded media, recovery and backups.
- PNG frames and MP4/H.264/AAC or WebM/VP9/Opus video, with progress and cancellation.

## Validation and source materials

Each of the five native builds must pass types, lint, documentation checks, unit tests, native video/audio export tests, packaged MP4/WebM export with an empty PATH, and desktop window/save/recovery tests before publication. The existing Windows CI also checks browser workflows and golden frames.

`SHA256SUMS.txt` covers every download. `AlgorithAct-FFmpeg-Sources-0.1.0.tar.gz` contains the exact checksum-verified FFmpeg, OpenH264, libvpx and Opus sources, source lock and build scripts used for all five packages. The application source is available in the source archives attached by GitHub. Third-party license texts and the media build configuration are also inside every app.

## Alpha limitations

The interface is currently in Uzbek. AI Build is a coming-soon screen; AI generation is not implemented. Installers have no publisher certificate; macOS apps use ad-hoc signing and are not notarized. OS security checks may restrict launching them. There is no automatic updater. Windows ARM64 and 32-bit systems do not have native packages in this release.

Please report reproducible problems with your OS, processor and a small synthetic project at [GitHub Issues](https://github.com/algorithco/AlgorithAct/issues).
